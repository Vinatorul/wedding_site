# Свадебное приглашение

Приглашение Саши и Сони на 16 октября 2026 года по референсу. Использованы присланные фотографии. Добавлены два виджета Яндекс Карт: Усадьба Воронцово (сбор в 11:20, регистрация в 11:40) и «Винил и Вино» (фуршет в 13:30).

Текст о дресс-коде пока демонстрационный. Анкета отправляет ответы через `POST /api/rsvp` и сохраняет их в SQLite.

Запуск из папки проекта:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --index-url https://pypi.org/simple -r backend/requirements.txt
.venv/bin/gunicorn --chdir backend --bind 127.0.0.1:4173 'app:create_app()'
```

Открой http://127.0.0.1:4173. Страница и API работают на одном адресе. Локальные ответы сохраняются в `backend/data/rsvp.sqlite3`; этот каталог исключён из Git.

Тексты находятся в `dist/content.js`, оформление — в `dist/styles.css`, структура — в `dist/index.html`. Фото и шрифты лежат в `dist/assets`. Осталось уточнить дресс-код. Карты требуют подключения к интернету; фотографии и шрифты хранятся локально.

Приглашение оформлено в палитре бургунди. Переключателя темы нет; старые ссылки с параметром `?theme=…` тоже открывают бургунди.

Для размещения на виртуалке с общим Docker-прокси Caddy используй [инструкцию деплоя](DEPLOYMENT.md) и `scripts/deploy-vm.py`. Домен и параметры сервера передаются при запуске; Node.js и npm не нужны. Ответы можно [выгрузить в CSV](DEPLOYMENT.md#выгрузка-ответов) скриптом `scripts/export-rsvp.py`.
