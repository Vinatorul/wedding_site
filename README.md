# Свадебное приглашение

Локальный макет приглашения Саши и Сони на 16 октября 2026 года по референсу. Использованы присланные фотографии. Добавлены два виджета Яндекс Карт: Усадьба Воронцово (сбор в 11:20, регистрация в 11:40) и «Винил и Вино» (фуршет в 13:30).

Текст о дресс-коде пока демонстрационный. Анкета проверяет заполнение, но не сохраняет и не отправляет ответы.

Запуск из папки проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открой http://127.0.0.1:4173. Тексты находятся в `dist/content.js`, оформление — в `dist/styles.css`, структура — в `dist/index.html`. Фото и шрифты лежат в `dist/assets`.

Осталось уточнить дресс-код и выбрать, куда отправлять ответы. До подключения отправки анкета явно работает как пример. Карты требуют подключения к интернету; фотографии и шрифты хранятся локально.

Два цветовых варианта доступны через переключатель вверху страницы и параметры `?theme=burgundy`, `?theme=autumn`. По умолчанию открывается бургунди. Выбор сохраняется в адресе страницы.

Для размещения на виртуалке с общим Docker-прокси Caddy используй [инструкцию деплоя](DEPLOYMENT.md) и `scripts/deploy-vm.py`. Домен и параметры сервера передаются при запуске; сборка и npm не нужны.
